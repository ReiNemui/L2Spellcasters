# L2 Spell Casters 1.0.0 日本語説明書

## 1. このModについて

L2 Spell Castersは、L2 Hostilityの敵にIron's Spells 'n Spellbooksの魔法を使わせる
NeoForge 1.21.1用アドオンModです。

対象の敵にはL2 Hostilityの特性として「魔導」が付きます。魔導を持つ敵は、個体ごとに
決められた魔法を状況に応じて使います。単に攻撃魔法を連発するだけでなく、距離、体力、
味方の負傷状態などを見て、攻撃、拘束、自己強化、回復、味方強化などを選択します。

主な特徴は次のとおりです。

- 敵ごとにランダムな魔法構成を生成します。
- 魔法構成は保存され、再起動やチャンクの再読み込み後も維持されます。
- 魔導ランクに応じて魔法数、レアリティ、魔法レベルが上昇します。
- L2 Hostilityの敵レベルに応じて魔法威力、マナ、詠唱速度などが成長します。
- 攻撃魔法や弱体化魔法では、敵同士の誤爆を防ぎます。
- 回復魔法や強化魔法は、負傷した敵の味方に使用できます。
- 敵へ一定以上のダメージを与えると、詠唱を中断できます。
- Configとデータパックで、多くの項目を変更できます。

## 2. 必要な環境

| 項目 | 対応内容 |
| --- | --- |
| Minecraft | 1.21.1 |
| Modローダー | NeoForge 21.1.251以上 |
| L2 Spell Casters | 1.0.0 |
| 必須Mod | L2 Hostility 3.0.18以上、4.0未満 |
| 必須Mod | Iron's Spells 'n Spellbooks 1.21.1-3.16系 |
| Java | Java 21 |

L2 HostilityとIron's Spellsが必要とする前提Modも導入してください。マルチプレイでは、
サーバーと参加者の両方へ同じMod構成を導入することを推奨します。

## 3. 導入方法

1. Minecraft 1.21.1用のNeoForge環境を用意します。
2. L2 HostilityとIron's Spells 'n Spellbooks、および両Modの前提Modを導入します。
3. `l2spellcasters-1.0.0.jar`をMinecraftの`mods`フォルダーへ入れます。
4. ゲームまたはサーバーを起動します。
5. 初回起動後、`config/enemyspellcast-common.toml`が生成されます。

すでに遊んでいるワールドへ後から導入する場合は、念のためワールドのバックアップを
作成してください。

## 4. 「魔導」特性

ゲームの言語設定が日本語の場合は「魔導」、英語の場合は「Spell Caster」と表示されます。
敵の頭上では「魔導1」「魔導3」のように、名前の後ろへランクが表示されます。

標準設定では次の条件を使用します。

| 項目 | 標準値 |
| --- | ---: |
| 出現可能になるL2レベル | 100 |
| 最大ランク | 5 |
| L2特性コスト | 80 |
| 自然抽選ウェイト | 100 |

魔導はレベル100以上の対象Mobへ付く可能性があります。必ず付くわけではなく、ほかの
L2特性と同様にランダム抽選です。L2の特性コストと敵レベルの条件により、おおむね
レベル400付近から最大ランク5が選ばれる可能性が出てきます。

次のMobは標準では対象外です。

- エンダードラゴン、ウィザー、ウォーデンなどのボス級Mob
- L2 Hostilityが管理する召喚・従属Mob
- 飼い主を持つMob
- Iron's Spellsが最初から魔法AIを持たせている魔術師系Mob

対象外リストはデータパックで変更できますが、召喚・所有関係に関する安全制限は優先されます。

## 5. ランクごとの成長

| 魔導ランク | 使用できる魔法数 | 使用できる最高レアリティ | 魔法レベルの目安 |
| ---: | ---: | --- | --- |
| 1 | 1 | Common | レベル1 |
| 2 | 1 | Uncommon | 最大レベルへ向けて約25% |
| 3 | 2 | Rare | 最大レベルへ向けて約50% |
| 4 | 2 | Epic | 最大レベルへ向けて約75% |
| 5 | 3 | Legendary | その魔法の最大レベル |

魔法は各枠とも候補からランダムに選ばれ、同じ個体の枠内では重複しません。最大ランクでは
最大3種類の魔法を使います。候補ごとに出現ウェイトが設定されているため、すべての魔法が
完全に同じ確率で選ばれるわけではありません。

魔法構成はMobへ保存されます。セーブ、チャンクのアンロード、サーバー再起動を挟んでも、
使用可能な魔法が候補に残っている限り同じ構成を維持します。

## 6. L2敵レベルによる能力成長

標準ではL2レベル100を基準とし、そこから50レベル上がるごとに1段階成長します。

| 能力 | レベル100の値 | 1段階ごとの成長 | 上限・下限 |
| --- | ---: | ---: | --- |
| 魔法威力 | 1.0倍 | +10% | 上限なし |
| 最大マナ | 100 | +20 | 上限なし |
| マナ回復 | 毎秒2 | 回復倍率+5% | 上限なし |
| 詠唱速度 | 1.0倍 | +5% | 最大3.0倍 |
| クールタイム | 1.0倍 | -5% | 最短25% |

例えば、標準設定のレベル400は基準から6段階上です。この場合、魔法威力は1.6倍、
最大マナは220、マナ回復は毎秒2.6、詠唱速度は1.3倍、クールタイムは通常の70%になります。

ここでいう魔法威力はIron's SpellsのSpell Power属性です。実際のダメージや回復量は、
各魔法自身の計算式や耐性などによって変わります。

`levelScaling.baseSpellPower`を`0.70`にすると、段階成長やほかの属性補正を含む最終的な
魔法威力を70%にできます。標準値は`1.0`なので、初期状態では従来の威力を変更しません。

## 7. 戦闘AIの仕様

魔導を持つ敵は、一定間隔で現在の状況を評価します。

- 敵との距離が魔法の射程に合っているか
- 射線が必要な魔法で、対象を視認できているか
- 現在のマナで使用できるか
- 魔法ごとのクールタイムが終わっているか
- 自分や周囲の味方が負傷しているか
- その状況で魔法を使う価値があるか

完全に同じ行動ばかりにならないよう、判断には小さなランダム要素も含まれます。魔法を
使えない状況では、通常の移動や近接攻撃など、そのMob本来のAIを引き続き使用します。

詠唱中も完全には停止せず、標準では通常の25%の速度で移動できます。射線を使う魔法では、
詠唱前に対象の方向を向きます。

## 8. 詠唱中断

標準設定では、1回の攻撃で最大体力の5%以上に相当するダメージを受けると詠唱が中断されます。
判定には防具や耐性で軽減された後のダメージを使用します。

中断された場合は、次の処理が行われます。

- 予定していた消費マナの25%を消費します。
- 20tick、つまり約1秒間の全体クールタイムが発生します。
- 発動前だった魔法の効果は発生しません。

必要な一撃ダメージ、消費マナ、再使用までの時間はConfigで変更できます。

## 9. 敵同士の誤爆防止と支援魔法

`general.friendlyFireProtection=true`の場合、魔導持ちの攻撃魔法や弱体化魔法は敵側の
味方へ作用しないよう保護されます。遅れて発生する投射物や召喚物についても、発生元を
判定できる範囲で保護します。

一方、回復や強化は敵の味方へ使用できます。AIは周囲から支援対象を探し、負傷状態などを
考慮して選択します。プレイヤーを敵側の回復対象として扱うことはありません。

特殊なアドオン魔法など、発生元を記録せずに直接効果を与える実装では、完全に保護できない
場合があります。

## 10. 標準の魔法候補

1.0.0では、標準の安全候補として48種類の魔法を収録しています。攻撃魔法だけでなく、
次のような種類を含みます。

- 単体攻撃、投射物、連鎖攻撃
- 範囲攻撃、弾幕系攻撃
- 鈍足、拘束、引き寄せなどの妨害
- 短距離移動や回避
- 自己強化
- 敵の味方に対する回復や強化

各個体がこの48種類すべてを使うわけではありません。魔導ランク、レアリティ、候補ごとの
最低ランク、出現ウェイトによって、その個体の魔法構成が決まります。

## 11. Config

設定ファイルは`config/enemyspellcast-common.toml`です。NeoForgeがファイル変更を
再読み込みした場合はゲーム中にも反映されますが、安全のため大きく変更した後は再起動を
推奨します。

### 基本設定

| 設定キー | 標準値 | 内容 |
| --- | ---: | --- |
| `general.enabled` | `true` | 魔導のAI全体を有効化 |
| `general.friendlyFireProtection` | `true` | 敵同士への攻撃・弱体化を防止 |
| `general.allowContinuousSpells` | `false` | 連続詠唱魔法の候補登録を許可 |

連続詠唱魔法は敵AIでの安全な実行を保証していないため、通常は`false`のままにしてください。

### レベル成長

| 設定キー | 標準値 | 内容 |
| --- | ---: | --- |
| `levelScaling.baseMobLevel` | `100` | 能力成長を開始するL2レベル |
| `levelScaling.levelStep` | `50` | 1段階成長するために必要なレベル |
| `levelScaling.baseSpellPower` | `1.0` | 段階成長を含む最終魔法威力倍率 |
| `levelScaling.spellPowerPerTier` | `0.10` | 1段階ごとの魔法威力上昇 |
| `levelScaling.baseMaxMana` | `100.0` | 基準最大マナ |
| `levelScaling.maxManaPerTier` | `20.0` | 1段階ごとの最大マナ上昇 |
| `levelScaling.baseManaRegenPerSecond` | `2.0` | 基準の毎秒マナ回復 |
| `levelScaling.manaRegenPerTier` | `0.05` | 1段階ごとのマナ回復倍率上昇 |
| `levelScaling.castSpeedPerTier` | `0.05` | 1段階ごとの詠唱速度上昇 |
| `levelScaling.castSpeedCap` | `3.0` | 詠唱速度の上限倍率 |
| `levelScaling.cooldownReductionPerTier` | `0.05` | 1段階ごとのクールタイム短縮 |
| `levelScaling.cooldownFloor` | `0.25` | クールタイムの最短倍率 |

### AIと詠唱中断

| 設定キー | 標準値 | 内容 |
| --- | ---: | --- |
| `behavior.decisionIntervalTicks` | `10` | 魔法を判断する間隔 |
| `behavior.randomScoreJitter` | `0.15` | 行動判断へ加えるランダム幅 |
| `behavior.interruptDamageFraction` | `0.05` | 詠唱中断に必要な最大体力割合 |
| `behavior.interruptManaFraction` | `0.25` | 中断時に消費する予定マナの割合 |
| `behavior.interruptGlobalCooldownTicks` | `20` | 中断後の全体クールタイム |
| `behavior.castingMoveSpeed` | `0.25` | 詠唱中の移動速度倍率 |
| `behavior.minimumCastScore` | `0.20` | 魔法を使うために必要な最低評価 |
| `behavior.supportSearchRange` | `16.0` | 回復・強化対象を探す距離 |

### 魔法候補の制御

| 設定キー | 標準値 | 内容 |
| --- | ---: | --- |
| `spellOverrides.selectionMode` | `DEFAULT_POOL` | 標準候補または許可リスト限定を選択 |
| `spellOverrides.allowedSpellIds` | `[]` | `ALLOWLIST_ONLY`時に許可する魔法ID |
| `spellOverrides.forceAllowSpellIds` | `[]` | 標準候補で明示的に許可する魔法ID |
| `spellOverrides.forceDenySpellIds` | `[]` | 必ず禁止する魔法ID |

`forceDenySpellIds`が最優先です。許可と禁止の両方へ同じIDを書いた場合は使用されません。

### 調整例

敵の魔法威力だけを70%へ下げたい場合は、次の値を変更します。

```toml
[levelScaling]
baseSpellPower = 0.70
```

標準候補の中から特定の魔法を禁止したい場合は、完全な魔法IDを指定します。

```toml
[spellOverrides]
forceDenySpellIds = ["irons_spellbooks:chain_lightning"]
```

許可リストに書いた魔法だけを使わせる場合は、次のようにします。

```toml
[spellOverrides]
selectionMode = "ALLOWLIST_ONLY"
allowedSpellIds = [
    "irons_spellbooks:fireball",
    "irons_spellbooks:root",
    "irons_spellbooks:teleport"
]
```

## 12. 召喚・地形変更・ポータル魔法

次のカテゴリは不具合やワールドへの影響が大きいため、標準では除外されています。

- Mobや特殊オブジェクトを呼び出す召喚魔法
- ブロックや地形を変更する魔法
- ポータル、帰還、ディメンション移動に関係する魔法

使用するには、カテゴリの除外設定を`false`にしたうえで、対象IDを許可リストへ明示する
二重許可が必要です。

| 設定キー | 標準値 |
| --- | ---: |
| `behavior.excludeSummoningSpells` | `true` |
| `behavior.excludeTerrainChangingSpells` | `true` |
| `behavior.excludePortalSpells` | `true` |

これらは非推奨の実験的機能です。召喚Mobの残留、意図しない地形破壊、移動失敗などが起きても
正式な動作保証の対象外です。試す場合は、必ずバックアップしたワールドを使用してください。

## 13. アドオンModの魔法

Iron's Spells向けアドオンModの魔法は、自動では候補へ追加されません。アドオン側の魔法が
Iron's SpellsのSpell Registryへ登録されていれば、データパックで魔法プール定義を追加する
ことで動く可能性があります。

一般的な投射物、攻撃、自己強化は比較的動きやすい一方、プレイヤー専用処理、独自能力、
独自ターゲット情報などを要求する魔法は動かない可能性があります。アドオン魔法は正式な
互換保証の対象外であり、「追加して正常に動けば使用できる」程度の扱いです。

## 14. データパックによる拡張

魔法候補は、次の場所へJSONを置くことで追加できます。

`data/<任意の名前空間>/enemyspellcast/spell_pool/*.json`

例は次のとおりです。

```json
{
  "spells": [
    {
      "spell": "another_spell_mod:arcane_bolt",
      "weight": 10,
      "min_trait_rank": 2,
      "target": "enemy",
      "behavior": "direct",
      "min_range": 2.0,
      "max_range": 24.0,
      "requires_line_of_sight": true,
      "safety_category": "standard"
    }
  ]
}
```

主な値は次のとおりです。

- `target`: `enemy`、`self`、`ally`
- `behavior`: `direct`、`target_entity`、`ally_self_cast`
- `safety_category`: `standard`、`summoning`、`terrain_change`、`portal`

追加したファイルは`/reload`で再読み込みできます。不明な魔法ID、無効な魔法、壊れた定義は
ログへ警告を出してスキップされ、ほかの正常な候補は引き続き読み込まれます。

## 15. よくある質問

### 魔導を持つ敵が出ません

- 対象のL2レベルが100以上か確認してください。
- 魔導はランダム抽選なので、条件を満たしても必ず付きません。
- ボス、召喚Mob、ペット、Iron's Spellsの魔術師系Mobは標準で対象外です。
- `general.enabled`が`true`か確認してください。
- 必須Modと対応バージョンが揃っているか確認してください。

### 魔導1しか見つかりません

高ランクほど必要なL2レベルと特性コストが高くなります。レベル400前後の敵を確認してください。
最大ランクが出現可能なレベルでも、必ずランク5になるわけではありません。

### 敵が魔法を使いません

- プレイヤーなどの攻撃対象が射程内にいるか確認してください。
- 魔法を使うためのマナや射線が不足している場合があります。
- 選ばれた魔法が現在の状況に合わず、通常攻撃を優先している場合があります。
- Configで候補をすべて禁止していないか確認してください。
- `logs/latest.log`で`EnemySpellCast`を検索すると、無効な魔法IDなどを確認できます。

### 敵の魔法が強すぎます

まず`levelScaling.baseSpellPower`を調整してください。`0.70`なら最終魔法威力が70%、
`0.50`なら50%になります。レベル上昇による成長を弱めたい場合は、
`spellPowerPerTier`も小さくしてください。

### 設定を変えたのに既存Mobへ反映されません

NeoForgeがConfigを再読み込みするまで少し待つか、ゲームまたはサーバーを再起動してください。
魔法プールをデータパックで変更した場合は`/reload`を実行します。

### アンインストールできますか

ワールドからModを外す前にバックアップしてください。魔導の保存データはMobに含まれますが、
Modを外した状態では利用できません。L2 HostilityやIron's Spells自体も使用中のワールドから
安易に削除しないでください。

## 16. 不具合を報告するときに必要な情報

問題が起きた場合は、次の情報をまとめてください。

- Minecraft、NeoForge、L2 Spell Castersのバージョン
- L2 HostilityとIron's Spellsのバージョン
- 導入している関連アドオンMod
- 問題が起きたMobのID
- L2レベルと魔導ランク
- 使用した、または使用しようとした魔法ID
- 該当するConfig設定
- `logs/latest.log`の該当部分
- クラッシュした場合はクラッシュレポート全文
- シングルプレイか専用サーバーか

## 17. 1.0.0時点の注意事項

- 召喚、地形変更、ポータル系魔法は実験的機能です。
- アドオンMod由来の魔法は正式な互換保証の対象外です。
- 大量の魔導持ちを同時に出現させると、通常より負荷が高くなります。
- Configを極端な値にすると、戦闘バランスや処理負荷が大きく変化します。
- 重要なワールドでは、Mod構成や設定を変更する前にバックアップしてください。
